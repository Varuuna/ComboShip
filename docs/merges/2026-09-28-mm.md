## Conflict resolutions

- `2s2h/BenPort.cpp` (alt-assets default) — took upstream. #1837 flipped `AlternateAssets` to
  default 0, which was our deviation; retired (it was only recorded in the initial-merge log).
- `ItemTracker.cpp` / `ItemTrackerSettings.cpp` — took upstream's `GetVanillaItemIdForSlot` at both
  call sites and moved our two needs into the helper in one `COMBO_BUILD` block: the dormant-MM
  peek gate (without it a peek shows ocarinas instead of the save's items) and the empty
  safe-item-list guard (the list fills lazily and can be empty on the first draw). The slot icon
  lookup skips `ITEM_NONE`, which is past the end of `gItemIcons` (also `COMBO_BUILD`).

## Post-merge changes

- **Shared Context kept alive (`BenPort.cpp` `DeinitOTR`).** #1879 added
  `Ship::Context::DestroyInstance()` to MM's teardown. It auto-merged, but in combo the Context is
  shared and soh's teardown runs after `MM_Deinit`, so it would run on a dead Context (crash on X).
  Now `#ifndef COMBO_BUILD`. After `MM_Deinit()` the Context is still alive and `SOH_Deinit()` is
  the only place that destroys it. See [deviations/boot-shutdown.md](../deviations/boot-shutdown.md).
- **Cherry-picked from develop:** the 5.0.0 skulltula fill-parity fix (`2339002639`: vanilla tokens
  from #1840's per-house shuffle emitted as `fixed[]`, see `docs/COMBO_FILL_PARITY.md`) and the mod
  order fix (`d8c99c6bd3`: MM's list moves to `gSettings.EnabledModsMM`, see
  [deviations/ui-menu.md](../deviations/ui-menu.md)). 5.0.1 now calls `ModMenu_LoadArchives()` from
  `InitOTR`, so MM rewrote the shared list even earlier without it. The develop-only `SetBlock`
  docs section was left out of the cherry-pick; that fix is not on main.
- `upstream-pins.json`: mm `remote` synced to `2ship2harkinian/2ship2harkinian` (repo moved).

Absorbed without changes:
- #1858 reorders `RandoCheckId`/`RandoOptionId`. Existing MM rando saves go stale; accepted.
- `RO_SKULLTULA_TOKENS_MAX` is gone; nothing in `combo/` used it.
- New file-setup screen (#1829) adds `gFileSel*` textures; regenerate `2ship.o2r`.
