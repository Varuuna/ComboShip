## Workflow fixes (root cause of the conflict storm)

history-based base derivation silently used pre-#47 bases and re-conflicted already-merged ranges
(~60 of the 64 blocks), and the soh merge ran with rename detection on, re-splicing the mm assets.

`merge-tree --merge-base` with `renames=false` for all folders + a cross-prefix tripwire;
`conflict-check.yml` now matches 8-char rename markers (`{7,}`). Replay of this cycle with the fixed
mechanism: 4 genuine conflicts instead of 64 blocks, no asset damage.
